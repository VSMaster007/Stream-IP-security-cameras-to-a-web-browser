# Screenshots

No screenshot files are stored in this directory. The images captured during local verification were browser-tool output, not files committed as product evidence.

A useful set, when you take them yourself, is:

1. Demo mode with the color-bar test pattern, source health Ready, and browser playback Live.
2. The same dashboard after Retry playback, back on Live.
3. Source health Offline after the demo publisher is stopped, with playback no longer Live.
4. The narrow layout below 800px, with the header, video, and status stacked.
5. Real-camera mode only after a camera you control is connected. Do not include the RTSP URL, a password, or the Control API address.

Avoid pictures of `.env`, `docker compose config`, container environment variables, or browser network logs that echo the camera URL.
